# Changelog

## 0.1.0

- RodiumAi API credential, checked against the authenticated wallet endpoint.
- RodiumAi Chat Model sub-node for AI Agents and chains, with `rodiumai/smart` as the default model. Model lists only show models that answer in text (no image, speech, audio, video or transcription models).
- RodiumAi action node: Chat › Create Completion (text and JSON) and Model › List Models.
- Actionable error messages for RodiumAi API errors (400, 401, 402, 403, 404, 429, 5xx).
